# ความเป็นส่วนตัวและ PDPA (Privacy by Design)

ระบบนี้ประมวลผลข้อมูลส่วนบุคคลของพนักงาน องค์กรผู้ใช้งานเป็น "ผู้ควบคุมข้อมูลส่วนบุคคล" ตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
เอกสารนี้สรุปสิ่งที่ระบบทำให้แล้ว และสิ่งที่องค์กรต้องดำเนินการเอง (ไม่ใช่คำแนะนำทางกฎหมาย ควรปรึกษา DPO / ที่ปรึกษากฎหมาย)

## สิ่งที่ระบบออกแบบไว้

| หลักการ | การทำงานในระบบ |
|---|---|
| เก็บเท่าที่จำเป็น (Data minimisation) | AI worker ไม่บันทึกภาพ/วิดีโอ ส่งเฉพาะสถานะ เวลา และค่าความมั่นใจ |
| ไม่ใช้ข้อมูลชีวมิติเพิ่ม | ระบุตัวบุคคลจากการจับคู่โต๊ะ ไม่ใช้ face recognition · ใช้ผลยืนยันตัวตนจากเครื่องสแกนเดิม ไม่เก็บลายนิ้วมือ/ใบหน้าซ้ำ |
| ไม่ตัดสินอัตโนมัติ | ข้อมูลจากกล้องไม่อยู่ในสูตร KPI (API ปฏิเสธการตั้งค่า) รายงานระบุชัดว่าเป็นข้อมูลประกอบ |
| ไม่วินิจฉัยสุขภาพ/อารมณ์ | ฟีเจอร์ Wellness ใช้แค่ระยะเวลานั่งต่อเนื่องและชั่วโมงทำงาน |
| สิทธิ์ของเจ้าของข้อมูล | พนักงานดูข้อมูลของตนเอง ขอแก้ไขได้ และได้รับแจ้งผลการพิจารณา |
| มนุษย์ตรวจสอบ | ทุกคำขอแก้ไขต้องผ่าน HR/หัวหน้างาน · รายงาน A4 มีช่องความเห็นและลายเซ็นผู้ประเมิน |
| จำกัดการเข้าถึง | RBAC 5 ระดับ · viewer ดูได้เฉพาะภาพรวม · employee ดูเฉพาะของตนเอง |
| ตรวจสอบย้อนหลังได้ | Audit log การเข้าสู่ระบบ การแก้ไข การออกรายงาน การส่งออกข้อมูล |
| ระยะเวลาเก็บรักษา | ลบข้อมูลกิจกรรมและการแจ้งเตือนอัตโนมัติตาม `retention_days` (ค่าเริ่มต้น 180 วัน) |
| ความโปร่งใส | ข้อความแจ้งเรื่องการใช้กล้องแสดงที่หน้าเข้าสู่ระบบ · บันทึกการยินยอมรายบุคคล |

## สิ่งที่องค์กรต้องทำก่อนใช้งานจริง

- [ ] กำหนดวัตถุประสงค์และฐานทางกฎหมายในการประมวลผล (เช่น ประโยชน์โดยชอบด้วยกฎหมาย) และทำ DPIA
- [ ] จัดทำและประกาศนโยบายความเป็นส่วนตัวสำหรับพนักงาน แจ้งตำแหน่งกล้องและข้อมูลที่เก็บ
- [ ] ปรึกษาตัวแทนพนักงาน/สหภาพ (ถ้ามี) และบันทึกการรับทราบ/ยินยอมในระบบ
- [ ] ไม่ติดตั้งกล้องในพื้นที่ส่วนตัว (ห้องน้ำ ห้องพัก ห้องให้นมบุตร ฯลฯ)
- [ ] กำหนดผู้มีสิทธิ์ดูภาพสดให้น้อยที่สุด และทบทวนรายชื่อผู้ใช้เป็นระยะ
- [ ] ตั้งค่า HTTPS (reverse proxy เช่น Caddy/Nginx) และทำตามเช็กลิสต์ใน [SECURITY.md](SECURITY.md) (ห้ามเปิดพอร์ต go2rtc 1984/8554 ออกนอกเครื่อง)
- [ ] ตั้ง `retention_days` ให้สอดคล้องกับนโยบาย และสำรองข้อมูลแบบเข้ารหัส
- [ ] กำหนดขั้นตอนรับเรื่องร้องเรียนและคำขอใช้สิทธิ์ของเจ้าของข้อมูล
- [ ] หากการบันทึกวิดีโอ (NVR) แยกจากระบบนี้ ให้กำหนดนโยบายการเก็บและการเข้าถึงภาพย้อนหลังด้วย
