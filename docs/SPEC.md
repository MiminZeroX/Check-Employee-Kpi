สถานะการพัฒนาของแต่ละหัวข้อดูได้ที่ [ROADMAP.md](ROADMAP.md)

## คำขอเดิม

## โครงการพัฒนาระบบ AI Smart Office Monitoring & Workforce Management System

### 1. วัตถุประสงค์ของโครงการ

ต้องการพัฒนาระบบบริหารจัดการบุคลากรและวิเคราะห์พฤติกรรมการทำงานภายในสำนักงานแบบครบวงจร โดยใช้เทคโนโลยี Artificial Intelligence (AI), Computer Vision, CCTV Analytics, Workforce Management และระบบ CRM ร่วมกัน

สามารถพัฒนาระบบขึ้นใหม่ หรือศึกษาและนำโครงการ Open Source ที่มีประสิทธิภาพมาพัฒนาต่อยอด เพื่อลดต้นทุนและระยะเวลาในการพัฒนา โดยตรวจสอบ License ความปลอดภัย และความเหมาะสมในการใช้งานระดับองค์กรด้วย

ระบบต้องมีประสิทธิภาพสูง ใช้ RAM และ CPU ต่ำ มีความเสถียร สามารถทำงานได้ตลอด 24 ชั่วโมง และรองรับการขยายระบบในอนาคต

### 2. ระบบ AI ตรวจจับกิจกรรมภายในสำนักงาน (AI Activity Detection)

พัฒนาระบบ AI Computer Vision สำหรับตรวจจับและจำแนกกิจกรรมของพนักงานผ่านกล้อง CCTV แบบ Real-time โดยสามารถตรวจจับเหตุการณ์ดังต่อไปนี้

- การนั่งประจำโต๊ะทำงาน
- การมองหน้าจอคอมพิวเตอร์
- การใช้งานโทรศัพท์มือถือ
- การหันหน้าหรือมองไปในทิศทางอื่น
- การไม่อยู่ที่โต๊ะทำงาน
- การเดินเข้าและออกจากพื้นที่ทำงาน
- การพูดคุยหรือประชุมร่วมกับเพื่อนร่วมงาน
- การพักระหว่างเวลาทำงาน
- การกลับมาประจำโต๊ะทำงาน
- การนั่งทำงานต่อเนื่องเป็นระยะเวลานาน

ระบบต้องสามารถบันทึกเวลาเริ่มต้น เวลาสิ้นสุด ระยะเวลาของแต่ละกิจกรรมเป็นวินาที นาที และชั่วโมง รวมถึงสรุปจำนวนครั้งที่เกิดเหตุการณ์ในแต่ละวัน

ต้องมีระบบ Confidence Score เพื่อประเมินความแม่นยำของ AI และกำหนดสถานะ Unknown ในกรณีที่ไม่สามารถจำแนกกิจกรรมได้อย่างมั่นใจ

ไม่ควรสรุปว่าพนักงานไม่ได้ทำงานจากการมองออกจากหน้าจอ การใช้โทรศัพท์ หรือการไม่อยู่ที่โต๊ะเพียงอย่างเดียว เนื่องจากอาจเป็นส่วนหนึ่งของการปฏิบัติงาน

### 3. ระบบบริหารจัดการกล้อง CCTV (Video Management System)

ออกแบบระบบบริหารจัดการกล้องวงจรปิดผ่าน Web Application โดยมีรูปแบบการใช้งานคล้าย Hikvision หรือระบบ VMS ระดับองค์กร

ความสามารถที่ต้องการ ได้แก่

- เพิ่ม ลบ และแก้ไขข้อมูลกล้อง CCTV
- รองรับ RTSP, ONVIF และ IP Camera
- รองรับกล้องจากผู้ผลิตหลายยี่ห้อ
- แสดงสถานะ Online และ Offline
- แสดงภาพสดผ่าน Web Browser
- รองรับมุมมองกล้องแบบ 1, 4, 9, 16, 25, 36 และ 64 ช่อง
- รองรับ Full Screen
- รองรับ PTZ สำหรับกล้องที่มีความสามารถดังกล่าว
- กำหนดพื้นที่ตรวจจับ Region of Interest (ROI)
- กำหนดตำแหน่งโต๊ะและพื้นที่ทำงาน
- เปิดหรือปิด AI Detection แยกตามกล้อง
- ปรับ FPS และความละเอียดในการประมวลผล AI
- ตรวจสอบความผิดปกติของกล้องและการเชื่อมต่อ
- ดูเหตุการณ์ย้อนหลังผ่าน Timeline ตามสิทธิ์ที่ได้รับ
- รองรับหลายอาคาร หลายชั้น หลายสำนักงาน และหลายสาขา

ควรแยกการประมวลผล Video Streaming ออกจาก AI Inference เพื่อเพิ่มประสิทธิภาพและลดภาระของ Server

### 4. ระบบเชื่อมต่อเครื่องสแกนเข้างาน (Attendance Integration)

พัฒนาระบบเชื่อมต่อกับเครื่องสแกนลายนิ้วมือ เครื่องสแกนใบหน้า และระบบบันทึกเวลาเข้าออกงานที่องค์กรใช้งานอยู่

รองรับการเชื่อมต่อผ่าน API, SDK, Webhook หรือระบบนำเข้าข้อมูลตามความสามารถของอุปกรณ์

ข้อมูลที่ต้องการ ได้แก่

- เวลาเข้างานและออกงาน
- เวลาเข้าสู่พื้นที่สำนักงาน
- เวลามาถึงพื้นที่โต๊ะทำงานที่ยืนยันได้
- ระยะเวลาระหว่างการสแกนเข้างานกับการมาถึงพื้นที่ทำงาน
- เวลาพักกลางวัน
- การทำงานล่วงเวลา
- การลาและวันหยุด
- การปฏิบัติงานนอกสถานที่
- ตารางเวลาทำงานของพนักงานแต่ละคน

ควรใช้ข้อมูลการยืนยันตัวตนจากระบบ Attendance ที่ได้รับอนุญาตเป็นหลัก โดยไม่จัดเก็บข้อมูลลายนิ้วมือหรือข้อมูลชีวมิติซ้ำโดยไม่จำเป็น

### 7. ระบบวิเคราะห์ข้อมูลและ KPI

พัฒนาระบบวิเคราะห์ข้อมูลรายบุคคล รายแผนก รายสาขา และภาพรวมองค์กร โดยสามารถเลือกช่วงเวลารายวัน รายสัปดาห์ รายเดือน รายไตรมาส และรายปี

ข้อมูลประกอบการวิเคราะห์ ได้แก่

- จำนวนชั่วโมงการทำงาน
- สถิติการเข้างาน
- ระยะเวลาการอยู่ในพื้นที่ทำงาน
- ระยะเวลาของกิจกรรมที่ AI ตรวจพบ
- จำนวนงานที่ได้รับมอบหมาย
- จำนวนงานที่ดำเนินการสำเร็จ
- อัตราการส่งงานตรงเวลา
- คุณภาพของผลงาน
- ประสิทธิภาพการดำเนินโครงการ
- ผลการประเมินจากผู้บังคับบัญชา
- ความพึงพอใจของลูกค้า
- ความสมดุลระหว่างการทำงานและการพักผ่อน

ระบบ KPI ต้องสามารถกำหนดน้ำหนักคะแนนตามตำแหน่งและลักษณะงานได้ โดยเน้นผลลัพธ์และคุณภาพของงานเป็นหลัก ไม่ใช้ข้อมูลจากกล้องเป็นคะแนนตัดสินประสิทธิภาพของพนักงานโดยอัตโนมัติ

### 8. ระบบรายงาน (Report Center)

สามารถสร้างรายงานอัตโนมัติในรูปแบบกระดาษ A4 ที่มีความเป็นมืออาชีพ พร้อมรองรับการพิมพ์และส่งออกไฟล์

รูปแบบรายงาน ได้แก่

- PDF A4
- Excel
- CSV
- Print Preview

รายงานควรประกอบด้วยข้อมูลพนักงาน แผนก ช่วงเวลาประเมิน สถิติการเข้างาน สรุปกิจกรรม ผลงาน KPI กราฟเปรียบเทียบ แนวโน้มการทำงาน ข้อเสนอแนะ และช่องสำหรับผู้ประเมิน

สามารถกำหนด Logo องค์กร หัวกระดาษ ท้ายกระดาษ เลขที่เอกสาร และรูปแบบรายงานได้จากหน้า Admin

### 9. ระบบส่งเสริมสุขภาพพนักงาน (Employee Wellness)

ระบบต้องไม่มุ่งเน้นเพียงการติดตามกิจกรรม แต่ต้องส่งเสริมสุขภาพและคุณภาพชีวิตของพนักงานด้วย

- แจ้งเตือนเมื่อนั่งทำงานต่อเนื่องเป็นเวลานาน
- แนะนำให้พักสายตาตามหลัก 20-20-20
- แนะนำให้ลุกเดินหรือยืดกล้ามเนื้อ
- ส่งเสริมการพักระหว่างเวลาทำงาน
- วิเคราะห์ภาระงานและการทำงานล่วงเวลา
- ส่งเสริม Work-Life Balance
- เปิดให้พนักงานตรวจสอบและแก้ไขข้อมูลที่คลาดเคลื่อนของตนเอง

ไม่ควรใช้ AI จากภาพกล้องเพื่อวินิจฉัยสุขภาพจิต อารมณ์ หรือโรคของพนักงาน

### 10. เทคโนโลยีและภาษาในการพัฒนา

ให้ความสำคัญกับประสิทธิภาพ ความปลอดภัย การใช้ RAM และ CPU ต่ำ รวมถึงความสามารถในการรองรับผู้ใช้งานและกล้องจำนวนมาก

เทคโนโลยีเบื้องต้นที่ควรศึกษาและเปรียบเทียบ ได้แก่

- Backend: Rust
- Backend Framework: Axum หรือ Actix Web
- Frontend: SvelteKit หรือ Vue.js
- UI: Tailwind CSS
- Database: MySQL
- Database Access: SQLx
- AI Inference: ONNX Runtime หรือ OpenVINO
- Computer Vision: OpenCV
- Video Processing: FFmpeg หรือ GStreamer
- Video Streaming: WebRTC
- Camera Protocol: RTSP และ ONVIF
- Real-time Communication: WebSocket
- Reverse Proxy: Nginx หรือ Caddy
- Deployment: Docker และ Docker Compose

สามารถใช้ Python สำหรับการฝึกโมเดล AI หรือการทดลองโมเดล และใช้ Rust สำหรับระบบ Production ในส่วนที่เหมาะสม

ควรทดสอบและเปรียบเทียบประสิทธิภาพจริงก่อนเลือก Technology Stack ขั้นสุดท้าย

### 12. ระบบความปลอดภัยและความเป็นส่วนตัว

ออกแบบระบบตามหลัก Security by Design และ Privacy by Design พร้อมพิจารณาการปฏิบัติตามกฎหมาย PDPA ของประเทศไทย

- Role-Based Access Control (RBAC)
- Multi-Factor Authentication (MFA)
- Single Sign-On (SSO)
- Data Encryption
- HTTPS/TLS
- Audit Logs
- API Rate Limiting
- Session Management
- Data Retention Policy
- Data Anonymization
- ระบบปกปิดใบหน้าในกรณีที่ไม่จำเป็นต้องระบุตัวตน
- ระบบตรวจสอบและแก้ไขข้อมูลโดยพนักงาน
- ระบบกำหนดสิทธิ์การดูภาพย้อนหลัง
- ระบบลบข้อมูลเมื่อครบกำหนด
- ระบบสำรองและกู้คืนข้อมูล

ต้องกำหนดวัตถุประสงค์และขอบเขตการติดตามให้ชัดเจน แจ้งพนักงานอย่างโปร่งใส และมีการตรวจสอบโดยมนุษย์ก่อนนำข้อมูลไปใช้ในการประเมินที่ส่งผลต่อพนักงาน

### 13. การออกแบบสถาปัตยกรรมระบบ

ออกแบบระบบให้เป็น Modular Architecture โดยแยกส่วนการทำงานออกจากกันอย่างชัดเจน

รองรับการติดตั้งทั้งแบบ On-Premises, Private Cloud และ Hybrid Deployment

ควรพิจารณาการประมวลผล AI แบบ Edge Computing เพื่อลดการส่งข้อมูลวิดีโอผ่านเครือข่าย ลดภาระ Server และเพิ่มความเป็นส่วนตัว

ระบบต้องรองรับการขยายจากสำนักงานขนาดเล็กไปสู่องค์กรที่มีหลายสาขา โดยไม่จำเป็นต้องเขียนระบบใหม่ทั้งหมด

### 14. สิ่งที่ต้องดำเนินการก่อนเริ่มพัฒนา

ให้วิเคราะห์และจัดทำเอกสารดังต่อไปนี้ก่อนเริ่มเขียนโค้ด

1. Software Requirements Specification (SRS)
2. Feasibility Study
3. Open Source Research & Comparison
4. Technology Stack Comparison
5. System Architecture Diagram
6. Database ER Diagram
7. API Specification
8. UI/UX Design
9. User Flow
10. Project Folder Structure
11. Development Roadmap
12. Hardware Requirements
13. RAM, CPU และ GPU Benchmark
14. Security & Privacy Assessment
15. Testing Strategy
16. Deployment Strategy
17. Maintenance & Monitoring Plan
18. Cost Estimation

แบ่งการพัฒนาเป็น Phase อย่างชัดเจน เริ่มจาก MVP ไปจนถึง Production โดยแต่ละ Phase ต้องสามารถทดสอบและตรวจสอบการทำงานได้จริง

เป้าหมายสูงสุดคือการสร้างระบบบริหารจัดการสำนักงานอัจฉริยะระดับองค์กรที่มีประสิทธิภาพ ใช้ทรัพยากรต่ำ มีความปลอดภัย สามารถขยายระบบได้ และช่วยส่งเสริมประสิทธิภาพการทำงานควบคู่กับสุขภาพและคุณภาพชีวิตของพนักงานอย่างยั่งยืน
